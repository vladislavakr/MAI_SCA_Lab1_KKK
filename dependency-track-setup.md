# Настройка Dependency-Track

## Запуск контейнеров

1. Убедитесь, что Docker установлен и запущен
2. Откройте терминал в текущей директории
3. Выполните команду:
   ```bash
   docker-compose up -d
   ```

4. Дождитесь запуска контейнеров (обычно 1-2 минуты)

## Первичный вход в веб-интерфейс

1. Откройте веб-браузер
2. Перейдите по адресу: http://localhost:8080
3. Используйте следующие данные для входа:
   - Логин: `admin`
   - Пароль: `admin`

4. После первого входа рекомендуется изменить пароль в настройках безопасности

## Проверка работы

- База данных PostgreSQL доступна на порту 5432
- Dependency-Track веб-интерфейс доступен на порту 8080
- Логи контейнеров можно просмотреть командой:
  ```bash
  docker-compose logs -f
  ```

## Остановка сервисов

Для остановки контейнеров выполните:
```bash
docker-compose down
```
